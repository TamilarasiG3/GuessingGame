# 🎯 Project Overview

This game randomly generates a number between 1 and 10.
If the user guesses wrong, the game provides step-by-step clues to guide the player toward the correct answer.

The difficulty increases with each wrong attempt, making the game fun, challenging, and educational.

# ✨ Features

🔢 Random number generation (1–10)

🧠 3 clues per number

Clue 1 → Easy

Clue 2 → Medium

Clue 3 → Tough

# 🎨 Modern Glassmorphism UI

📱 Responsive & mobile-friendly design

🔁 Automatic reset after correct guess

🏏 Fun cultural reference (e.g., Dhoni jersey number for 7)

# 🧩 Game Logic
Attempt	What Happens
1st wrong guess	Clue 1 is shown
2nd wrong guess	Clue 2 is shown
3rd wrong guess	Clue 3 is shown
Correct guess	New number is generated
🛠️ Technologies Used

HTML5 – Structure

CSS3 – Styling & UI effects

JavaScript (ES6) – Game logic
